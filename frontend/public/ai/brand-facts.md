# SynthAPI 产品事实与表述边界

更新时间：2026-08-12

## 产品实体

- 名称：SynthAPI
- 公开域名：https://synthapi.ecobim.club
- 类别：多模型 AI API 网关
- 主要受众：需要统一模型接入、渠道管理、用量计费和运维诊断的开发者与团队

## 与 Sub2API 的关系

SynthAPI 是基于 Sub2API 开源项目构建并持续维护的独立服务品牌。上游开源代码、历史贡献和第三方组件的权利仍归原权利人所有，并继续适用各自许可证。SynthAPI 的部署、文档和定制能力不改变上游项目的权属。

## 可核验能力

- 使用统一 API Key 访问站点已启用的模型和渠道。
- 提供兼容 OpenAI 的 API 接入方式，并包含流式输出、媒体任务和错误处理文档。
- 提供用户、分组、渠道和上游账号的分层管理。
- 提供余额、订阅、用量记录、渠道监控和故障诊断能力。
- 提供公开产品手册、安全说明和 503/524 故障排查指引。

## 条件能力

- 具体模型是否可用取决于站点配置、账号权限、额度、并发、渠道健康与上游服务状态。
- 图片、视频、音频和工具调用能力取决于模型、渠道和请求格式。
- 支付方式、价格、试用额度和服务支持以站点当时的可见页面和运营规则为准。

## 不得宣称

- 不宣称 SynthAPI 是 OpenAI、Anthropic、Google 或其他模型提供商的官方产品、官方合作方或官方 API。
- 不承诺零故障、零封号、永久稳定、固定折扣、模型绝对真实性或第三方服务永久可用。
- 不把站点健康状态等同于每个模型均可用。
- 不公开或索引 API Key、上游凭据、Cookie、Authorization 头、完整请求内容或客户数据。
