SynthAPI 新手完整教程

从创建密钥到发出第一条请求，按顺序完成四步即可开始使用。

1. 创建 API Key

登录控制台，打开“API 密钥”页面并创建密钥。请将密钥保存到密码管理器或服务端环境变量，不要放到前端代码、截图或公开仓库中。

2. 设置地址并确认模型

OpenAI 兼容客户端的 Base URL 填写 https://synthapi.asia/v1，然后先调用模型列表：

curl https://synthapi.asia/v1/models \
  -H "Authorization: Bearer <你的 API Key>"

从返回结果中复制一个可用的 id，作为后续请求的 model。

3. 发出第一条文字请求

curl https://synthapi.asia/v1/chat/completions \
  -H "Authorization: Bearer <你的 API Key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"<模型 ID>","messages":[{"role":"user","content":"你好，请用一句话介绍 SynthAPI"}]}'

收到 200 和 choices 后，说明认证、线路和模型都已配置正确。

4. 图像和视频任务

图像使用 /v1/images/generations，视频使用 /v1/videos/generations。异步接口会返回 task_id，保存它后请求 /v1/tasks/{task_id} 查询状态。

5. 查看费用和排查问题

在使用日志中核对 Token、图片规格、视频任务和最终费用。401/403 检查密钥权限，404 检查模型或路径，429 检查频率限制，5xx 使用 request id 联系管理员。

安全清单

  • 不在前端公开真实 API Key。
  • 不把密钥提交到 Git。
  • 按应用分配密钥，需要时及时禁用或轮换。
