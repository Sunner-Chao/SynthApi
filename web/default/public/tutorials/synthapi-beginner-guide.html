SynthAPI × CC Switch 新手手把手教程

通过 CC Switch 保存 SynthAPI 配置，并在 Claude Code、Codex、Gemini CLI 之间快速切换供应商。

CC Switch 官网 官方下载 深链接生成器
先准备两样东西一个 SynthAPI API Key 和官方 CC Switch 客户端。真实密钥只在 CC Switch 本地填写，不要写入网页、截图、视频或公开深链接。

1. 安装 CC Switch

下载：从官方 Releases 下载与你系统对应的安装包。
启动：安装后打开 CC Switch，确认可以看到供应商列表或应用切换页面。
核对来源：不要使用第三方重新打包的安装包。

2. 添加 SynthAPI

手动添加

  1. 点击右上角“+”或“添加供应商”。
  2. 选择“自定义”或“OpenAI Compatible”，名称填写 SynthAPI。
  3. 填写 API Key 和从模型列表复制的模型 ID。
  4. 保存后点击 SynthAPI 卡片上的“启用”。
工具协议地址说明
Claude CodeAnthropic Messageshttps://synthapi.asia/anthropic/v1不要重复追加路径
CodexOpenAI Responseshttps://synthapi.asia/v1选择 Responses 协议
Gemini CLICC Switch Gemini 或自定义https://synthapi.asia 或 /v1按客户端字段要求选择

深链接导入

  1. 打开官方深链接生成器。
  2. 选择应用，填写端点、名称和模型 ID，API Key 留空。
  3. 点击生成并打开 ccswitch://v1/import... 链接。
  4. 回到 CC Switch 检查本地 API Key，再保存并启用。
ccswitch://v1/import?resource=provider&app=codex&name=SynthAPI&endpoint=https%3A%2F%2Fsynthapi.asia%2Fv1&apiKey=&model=MODEL_ID&enabled=true

深链接只是导入模板。不要把真实 apiKey 放进浏览器历史、聊天记录或公开网页。详细字段可参考 CC Switch 中文说明。

3. 配置三个工具

Claude Code

在 CC Switch 选择 Claude，使用 Anthropic Messages 和 https://synthapi.asia/anthropic/v1。启用后关闭旧终端并重新打开 Claude Code。

Codex

在 CC Switch 选择 Codex，使用 OpenAI Responses 和 https://synthapi.asia/v1。重新打开终端后再发送请求。

Gemini CLI

优先选择 CC Switch 的 Gemini 供应商；如果需要自定义 OpenAI 兼容供应商，使用 https://synthapi.asia/v1，模型以模型列表返回为准。

4. 切换并验证

在 CC Switch 点击另一张供应商卡片的“启用”。关闭仍在运行的 CLI，重新打开终端后验证：

curl https://synthapi.asia/v1/models \
  -H "Authorization: Bearer <你的 API Key>"

从返回的 id 复制一个模型，再发出最小请求：

curl https://synthapi.asia/v1/chat/completions \
  -H "Authorization: Bearer <你的 API Key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"<模型 ID>","messages":[{"role":"user","content":"你好，请用一句话介绍 SynthAPI"}]}'

HTTP 200 且返回 choices，通常表示认证、地址和模型配置成功。

5. 图像、视频和用量

图像使用 /v1/images/generations，视频使用 /v1/videos/generations。异步任务返回 task_id，保存后查询 /v1/tasks/{task_id}。在使用日志中核对模型、Token、任务状态和费用。

常见问题

现象排查
401/403检查 API Key、权限和是否误用了另一套密钥。
404检查协议和路径；Anthropic 使用 /anthropic/v1，OpenAI 使用 /v1。
429降低并发或等待额度恢复。
切换后仍是旧线路关闭旧 CLI 和终端，再重新打开。
深链接无法打开先安装并启动 CC Switch，或改用手动添加。

视频手把手教程方案

正式视频按以下镜头顺序录制，所有真实密钥均打码：安装官方 CC Switch → 创建并安全保存 SynthAPI Key → 手动添加 → 深链接导入 → 分别配置 Claude Code、Codex、Gemini CLI → 重启终端 → 请求 /v1/models → 发送最小请求 → 切换供应商并排查错误。视频发布后会从文档页“观看视频教程”入口打开。

密钥安全清单

  • 不在前端代码、截图、视频、公开 Issue 或 Git 中出现真实 API Key。
  • 不分享包含 apiKey= 的深链接。
  • 按项目分配密钥，泄露后立即禁用并轮换。
